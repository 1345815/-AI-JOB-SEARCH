# Behavioral Profile

## Overview
马育琪的行为特征呈现为**自主驱动-快速验证型**。喜欢快节奏、高挑战的工作环境，习惯独立从0到1开发产品并通过真实用户反馈验证想法。具备跨学科学习能力与结构化思维，善于从复杂系统中提炼可复用的知识框架。

## Core Behavioral Drives

| Drive | Level | Meaning |
|-------|-------|---------|
| 成就驱动 | 高 | 以"从0到1做出产品并看到用户使用"为核心动力 |
| 自主探索 | 高 | 习惯独立开发、自主试错、快速迭代 |
| 学习驱动 | 高 | 跨学科学习（飞行器工程→AI产品→游戏策划），持续拓展新领域 |
| 竞争驱动 | 中高 | 喜欢高挑战环境，参与竞赛并获奖 |

## Strongest Behaviors
- **产品从0到1的执行力：** 独立完成多个产品的设计、开发、上线与迭代（简历匹配分析器、招聘管理平台、游戏Demo）
- **结构化拆解能力：** 将复杂系统（SLG游戏玩法、获客链路、沟通方法）拆解为可复用的知识结构
- **用户洞察与共情：** 在猿辅导大量用户沟通中沉淀结构化沟通方法，在游戏推广中理解新手体验与区服生态
- **数据驱动思维：** 用数据度量效果并反推设计决策（降低操作成本40%、首屏加载<1.5s）
- **跨学科迁移能力：** 飞行器工程的系统工程思维迁移至游戏策划与AI产品开发

## How You Work Best
- 快节奏、有挑战的环境，能快速试错和迭代
- 自主性强的团队氛围，鼓励从想法到原型的快速验证
- 跨团队协作场景，能发挥结构化沟通与共情表达优势
- 有明确目标且能度量效果的工作

## Growth Areas (frame positively in applications)
- **大厂协作经验：** 目前以独立开发为主，可强调"独立开发培养了全链路产品思维，期待在大团队中学习协作与规模化落地"
- **英语口语：** CET-4水平读写可以，口语一般，可强调"能阅读英文技术文档，持续提升口语以适应国际化环境"

## Mapping to Job Posting Language

When a job posting mentions these keywords, it's a **strong behavioral fit**:
- "从0到1"、"独立负责"、"产品落地"、"用户增长"
- "AI驱动"、"LLM"、"Prompt工程"、"Agent"
- "数据驱动"、"效果度量"、"A/B测试"
- "游戏策划"、"系统拆解"、"商业化"、"留存"
- "快节奏"、"高挑战"、"创新驱动"

When a job posting mentions these, flag as **potential friction** (not deal-breaker):
- "5年以上经验" — 应届生经验有限
- "英语流利/工作语言" — CET-4口语一般，需FLAG
- "大规模团队管理" — 主要为独立开发经验

## Management Style Preferences
- 适合：目标导向、给予自主权、鼓励试错的管理风格
- 不适合：微观管理、流程繁琐、不允许试错的环境

## Using This in Applications
- **Cover letters:** 突出"从0到1独立开发AI产品并上线"的经历，强调快节奏环境下的执行力
- **CV:** 强调独立开发项目、量化成果、跨学科背景
- **Interviews:** 用STAR示例展示产品落地、数据驱动、跨团队协作能力
- **Don't overstate:** 不要夸大团队管理经验（以独立开发和团队队长经验为主），不要声称英语流利
