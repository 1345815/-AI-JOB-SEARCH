# CareerPilot AI 填网申（浏览器插件）

在任意企业网申页面，用你的 CareerPilot 档案一键自动填表。对标「求职方舟」的 AI 填网申。

## 功能

- 页面检测到表单时，右下角出现「🤖 AI 填表」浮动按钮
- 点击后从 CareerPilot 拉取你的档案，按字段语义自动匹配填充（姓名/手机/邮箱/学校/学历/专业/毕业时间/英语等级/性别/意向城市/经历概述）
- 已填字段绿色高亮，填完弹出汇总确认；**最终提交前请人工核对**

## 安装

1. 在 CareerPilot 网页版登录 → **设置 → 填表插件 → 获取令牌 → 复制**
2. 打开 Chrome，访问 `chrome://extensions`
3. 右上角开启「开发者模式」
4. 点「加载已解压的扩展程序」，选择本目录 `tools/autofill-extension`
5. 点扩展图标，填入：**服务地址**（如 `https://111.230.228.15:8000`）+ **插件令牌** → 保存 → 测试连接

## 使用

- 打开任意企业网申页面（北森/智联招聘/企业官网等），等右下角按钮出现
- 点「🤖 AI 填表」→ 核对高亮字段 → 手动补齐特殊字段 → 提交

## 安全说明

- 插件只读取你的档案（经 `/api/ext/profile`，Bearer 令牌认证），**不上传任何表单数据**
- 令牌泄露可在设置页「轮换」立即作废
- 不会自动提交表单——提交永远由你完成
