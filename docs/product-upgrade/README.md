## 三、全局约束（所有阶段必须遵守）

1. **不破坏现有测试**：`tests/` 全量通过（当前 24 个文件）；每次改动后跑 `python -m pytest -q` 与 `python -m compileall web`。
2. **不破坏 API 契约**：`web/static/` 前端依赖的 `/api/*` 路由、字段名、返回结构保持不变；只允许新增路由。
3. **最小依赖原则**：纯标准库优先，`requirements.txt` 不得无故新增；生产为离线 bundle 部署。
4. **Python 版本**：容器 `python:3.12-slim`，本地 Python 3.8；新代码若用 3.9+ 语法加 `from __future__ import annotations`。
5. **迁移纪律**：新表走 `init_db()` 的 `executescript` + `CREATE TABLE IF NOT EXISTS`；已有表加列走 `PRAGMA table_info` + `ALTER TABLE`（参照 `web/server.py:405-414`）。
6. **安全底线**：`api_key` 不得出现在日志/返回体；所有新增 API 保持现有安全头；admin 接口必须校验 `role=='admin'`，非 admin 一律 403。
7. **commit 纪律**：每阶段完成后单条 commit，message 带 `feat:` 前缀；回滚以 commit 为单位。
8. **前端纪律**：`app.js` 是 2010 行单文件，新页面/新视图优先复用现有 `render*` 模式与 `api()` helper；样式复用 `app.css` 既有 class。
