# 12 · 租户与团队协作改进提示词

## 🩺 根因诊断

| 坑 | 当前表现 | 排查命令 |
|---|---|---|
| 单用户模型 | 所有数据挂 `user_id`，无团队/组织维度，无法协作 | `grep -n "user_id" web/server.py`（全部个人维度） |
| 无共享能力 | 岗位/申请/简历无法共享给他人，内推场景不可用 | `grep -n "share\|team" web/server.py`（无结果） |
| 无邀请机制 | 用户之间无任何关联方式 | 无 team/邀请相关表 |
| 数据隔离 | 即便加共享，也需保证团队内可见、团队外不可见 | 无 team_members 关联 |

**最常见组合**：① + ② —— 先建团队模型与成员表，共享与邀请基于它才能落地。

4. 数据权限雏形：团队成员可在团队页看到彼此的公开用户名（仅展示，不共享业务数据——共享岗位为远期）

     CREATE TABLE IF NOT EXISTS teams (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       name TEXT NOT NULL,
       invite_code TEXT UNIQUE NOT NULL,
       owner_user_id INTEGER NOT NULL,
       created_at TEXT DEFAULT (datetime('now','localtime')),
       FOREIGN KEY (owner_user_id) REFERENCES users(id) ON DELETE CASCADE
     );
     CREATE TABLE IF NOT EXISTS team_members (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       team_id INTEGER NOT NULL,
       user_id INTEGER NOT NULL,
       role TEXT DEFAULT 'member',
       joined_at TEXT DEFAULT (datetime('now','localtime')),
       UNIQUE(team_id, user_id),
       FOREIGN KEY (team_id) REFERENCES teams(id) ON DELETE CASCADE,
       FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
     );
     CREATE INDEX IF NOT EXISTS idx_team_members_user ON team_members(user_id);
   - 新增 helper：generate_invite_code()（secrets.token_hex(4) 大写）、create_team(owner_user_id, name)、join_team(user_id, invite_code)、list_my_teams(user_id)、list_team_members(team_id)、leave_team(user_id, team_id)、team_member_count(team_id)

     - GET /api/teams/<id>/members → 成员列表（仅成员可见，非成员 403）
